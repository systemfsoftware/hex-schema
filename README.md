# hex-schema

Effect Schema definitions for hexadecimal wire formats, plus extra hex codecs: strict, colon-delimited, prefixed and byte-level schemas with branded types.

## Packages

- [`@systemfsoftware/effect-schema-extensions`](packages/effect-schema-extensions/README.md): Extra Effect Schema codecs — hex-string, prefixed-hex, colon-hex, and byte-level schemas with branded types, decode/encode, and arbitraries.
- [`@systemfsoftware/hex-schema`](packages/hex-schema/README.md): Effect Schema definitions for hexadecimal wire formats — strict, colon-delimited, prefixed, and byte-level schemas with branded types.

## Install

```bash
pnpm add @systemfsoftware/effect-schema-extensions @systemfsoftware/hex-schema
```

The npm registry lags this repository's sources: `@systemfsoftware/effect-schema-extensions` is 1.0.0 on npm and 1.0.3 here; `@systemfsoftware/hex-schema` is 2.0.0 on npm and 2.0.3 here. Each package's README describes its current source.
